# Used Car Price Prediction ML System

End-to-end machine learning project predicting used car prices using Ridge Regression.

## Features
- Data cleaning & EDA
- Feature engineering
- Model tuning
- FastAPI backend
- Streamlit frontend

## Tech Stack
Python, Scikit-learn, FastAPI, Streamlit

## Run Locally
pip install -r requirements.txt
uvicorn api.main:app --reload
streamlit run app/app.py
